# SOC Incident Investigation: Phishing to Ransomware

## Overview
This repository contains a comprehensive Incident Response (IR) report for a simulated cybersecurity incident. The scenario involves a targeted phishing campaign that resulted in a ransomware deployment on an employee workstation. 

## Scenario Summary
- **Threat Actor:** Organized Crime Group (Financial Motivation)
- **Initial Access:** Spear-phishing email with a malicious attachment
- **Impact:** Local file encryption on a single workstation, potential lateral movement blocked.
- **Framework:** NIST SP 800-61r2 Incident Handling Guide & MITRE ATT&CK.

## Why this report exists
This report is designed to demonstrate practical SOC Analyst skills, including:
- Alert triage and investigation methodology.
- Log analysis (Windows Event Logs, EDR, Firewall).
- IOC extraction and threat intelligence enrichment.
- Clear, structured communication of technical findings to both technical and non-technical stakeholders.

## Repository Structure
- `incident-report.md`: The full, detailed IR report.
- `evidence/`: Contains redacted logs, screenshots, and IOC lists used during the investigation.

*Note: This is a fictional scenario created for educational and portfolio purposes.*
